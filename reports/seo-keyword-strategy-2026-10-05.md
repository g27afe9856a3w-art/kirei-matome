# 流入ゼロの原因と、キーワード設計の作り直し提案（2026-10-05）

## 1. 事実の確認

| 指標 | 実績 |
|---|---|
| 公開記事 | 25本（2026年4月に集中投入、以降は新規なし） |
| 週間PV | 0〜3（直近4週：0 / 3 / 1 / 3） |
| Search Console クリック | **5月以降ずっと 0件** |
| Search Console 表示回数 | **直近4週すべて 0件** |
| 技術面 | sitemap 200・robots許可・noindexなし・GA4稼働（問題なし） |

**表示回数が「少ない」ではなく「ゼロ」である**ことが重要。
クリックされないのではなく、そもそも検索結果に出ていない。

## 2. 原因の診断

技術的な問題は見つからなかった。原因は**狙っているキーワードと記事の実力の乖離**にある。

### 原因A：全記事が2語の激戦キーワードを狙っている

`keywords.csv` の25件の内訳：

| 語数 | 本数 | 例 |
|---|---:|---|
| 1語 | 3 | `紫外線対策` `飲む日焼け止め` `セルフホワイトニング` |
| 2語 | 20 | `脱毛クリニック おすすめ` `医療ダイエット おすすめ` `AGA治療 おすすめ` |
| 3語以上 | 2 | `脱毛サロン クリニック 違い` `女性 プロテイン おすすめ` |

「◯◯ おすすめ」は日本語SEOで最も競合が激しい商用キーワード。
大手比較メディア・企業運営サイト・広告が占めており、
開設5か月・25記事・被リンクなしのサイトが入る余地はほぼない。

### 原因B：記事が狙うキーワードに対して圧倒的に短い

| 本文字数 | 本数 |
|---|---:|
| 1,700字未満 | 16本 |
| 1,700〜3,000字 | 2本 |
| 3,000字以上 | 7本 |

平均2,068字。最短は1,063字。

一方、「脱毛クリニック おすすめ」で上位表示されているページは
1万〜3万字規模で、独自の取材・料金の実地調査・体験写真を備えている。
**1,100字の記事が同じキーワードで競合するのは構造的に不可能。**

### 原因C：内部リンクが薄く、回遊しない

内部リンク平均2.8本。`face-datsumo-guide` `summer-uv-care` `medical-diet-clinic` は**0本**。

---

## 3. 提案：2語の商用キーワードを捨て、ロングテールに寄せる

### 考え方

いまの記事の長さ（1,000〜2,000字）で勝てるのは、
**検索する人が少ないが、悩みが具体的で、競合が手を出していない**キーワード。

| やめる（勝てない） | 狙う（勝てる可能性がある） |
|---|---|
| 脱毛クリニック おすすめ | 脱毛 1回目 どのくらい減る |
| 医療ダイエット おすすめ | GLP-1 やめたら リバウンド |
| AGA治療 おすすめ | AGA 治療費 医療費控除 |
| VIO脱毛 おすすめ | VIO脱毛 生理中 施術できる |
| コラーゲンサプリ おすすめ | コラーゲン 飲む タイミング 夜 |

共通点は「**疑問形・条件つき・3〜5語**」であること。
こうしたキーワードは検索数が月10〜100程度でも、
25本×複数キーワードで積み上げれば流入の足場になる。
そして何より、**まず表示回数が0から動く**。

### 既存25記事の扱い（捨てずに活かす）

| 方針 | 対象 | やること |
|---|---|---|
| **深掘り（ハブ化）** | `datsumo-clinic-ranking` `medical-diet-clinic` `whitening-clinic-guide` の3本 | 1万字規模まで育てる。料金の再調査を含む。ここだけは商用キーワードを狙い続ける |
| **ロングテール化** | 残り22本 | タイトルと見出しを具体的な疑問形に寄せ、その疑問に答える節を追記（+1,000〜2,000字） |
| **内部リンク補強** | 内部リンク0本の3本 | ハブ記事へ繋ぐ |

### 新規記事より先にやること

新規記事を書き足すより、**既存25本をロングテール向けに作り直すほうが先**。
25本が0件表示のまま本数を増やしても、0が増えるだけになる。

## 5. この提案の限界（正直に）

- **検索ボリュームと競合難易度を数値で検証していない。** 母艦にキーワードツールの
  接続がないため、上記は記事の長さ・キーワードの語数・SERPの一般的な傾向からの推定。
- Ahrefs / Similarweb の接続がこのセッションで使える状態になれば、
  実際の検索数と難易度を取って裏取りできる。認証が必要なので社長の操作がいる。
- **インデックス状況を未確認。** `site:` 検索はツールの制約（米国向け検索）で
  判定できなかった。Search Consoleの画面で見るのが確実。
- 効果が出るまで**最短でも2〜3か月**かかる。即効性のある打ち手ではない。

## 6. 補足：今日見つかった別の懸念

記事の料金情報（「全身脱毛49,800円〜」等）は**4月時点の調査のまま**で、
6か月間更新されていない。本日タイトルを「【2026年最新】」に統一したが、
中身の料金が古いままだと表示と実態が食い違う。
ハブ記事の深掘り（優先度3）で料金の再調査を必ず含めること。

## 追記（同日）：インデックス状況が判明 — 最大の原因はこちら

`scripts/index_check.py`（Search Console URL検査API）で全ページを確認した結果:

| 状態 | 件数 |
|---|---:|
| Googleに登録済み | **3 / 26**（トップ・collagen-supplement-ranking・protein-ranking） |
| Googleが存在を知らない | **16** |
| クロール済み・未登録（中身を見て見送り） | 7 |

さらに、**Googleが sitemap を最後に読んだのは 2026-04-19** で、5か月半読み直されていなかった。

つまり表示回数ゼロの第一の原因は「順位が低い」ではなく**「検索結果の候補にすら入っていない」**こと。
上の「優先順位」表の1番（インデックス確認）は完了し、この結果を受けて順序を改める：

1. **sitemap の再送信**（APIで実施。結果は `reports/index-status-*.md`）
2. **主要ページの登録リクエスト**（Search Console 画面の「URL検査 → インデックス登録をリクエスト」。1日10件程度まで。ハブ記事3本から）※APIでは不可、社長の操作が必要
3. 「クロール済み・未登録」の7本は中身の強化が必要（本レポートのロングテール化・ハブ化の方針どおり）
4. ロングテール化・ハブ化
